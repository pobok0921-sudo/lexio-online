📖 게임 설명

손에 든 타일을 가장 먼저 다 내는 사람이 승리! 🏆

🔢 숫자 서열 (높을수록 셈)

3 < 4 < 5 … < 14 < 15 < 1 < 2 (1·2가 가장 높음, 그중 2가 최강)

🎨 색상 서열 (같은 숫자일 때)

구름 ☁ < 별 ★ < 달 🌙 < 해 ☀

🃏 낼 수 있는 조합 (족보)
  • 싱글 1장 · 페어 같은숫자 2장 · 트리플 같은숫자 3장
  • 메이드 5장 — 약한 순서:
    스트레이트 < 플러쉬 < 풀하우스 < 포카드 < 스트레이트플러쉬

스트레이트=연속 5숫자 / 플러쉬=같은색 5장 / 풀하우스=3+2 / 포카드=4+1 / 스트플=같은색 연속5

▶ 게임 진행
  • 구름3 가진 사람이 선(첫 차례) — 선은 아무 조합이나 자유롭게 시작
  • 다음 사람은 같은 장수·같은 유형이면서 더 높은 패를 내거나 패스
  • 메이드(5장)는 더 높은 족보로 덮을 수 있음 (예: 스트레이트 위에 플러쉬)
  • 나 빼고 모두 패스하면 → 내가 다시 선이 되어 새로 시작
⭐ 스트레이트 특별 규칙

가장 강한 스트레이트: 1-2-3-4-5 > 2-3-4-5-6 > …-1
숫자 2는 스트레이트 맨 끝에 올 수 없어요

💰 점수 계산
  • 라운드 끝나면 남은 타일 수로 1:1 정산 (적을수록 이득)
  • ⚠️ 끝날 때 숫자 2를 들고 있으면 개수당 ×2 페널티! (2가 2개면 ×4)
🎤 기타
  • 게임 중 "길게 눌러 말하기"로 같은 방 사람들과 음성 대화
  • 타일을 눌러 선택 → 내기 / 낼 수 없으면 패스 · 정렬로 순서 정리
  • AI 난이도는 1급(입문)~5급(최고수), 숫자 클수록 강함

라운드 종료

숫자2 보유 시 남은 타일 × 2^(2의 개수)로 계산 후 1:1 정산 (합계 0)
